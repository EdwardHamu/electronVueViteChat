# 产品历史：内嵌日志与横竖屏布局

## 实现

- `src/views/Home/product/productHistory/index.tsx` 删除日志抽屉、入口按钮及废弃状态；ProductLog 与 Statistic 常驻同一页，共用当前选中记录。
- 横屏：历史列表占左侧 45%；右侧 55% 内统计在上、日志在下，两个区域各占右侧一半高度。
- 竖屏：历史列表、统计、日志依次纵向排列，内容区高度按 40% / 30% / 30% 分配。
- 页面本地通过 VueUse `useMediaQuery` 监听视口方向，窗口调整时自动切换，不改变全局方向判断。
- 内容区最小高度横屏 420px、竖屏 720px；较矮视口使用外层滚动，底部取消按钮独立占位。三个表格保留纵向虚拟滚动，取消 scrollX 和列拖拽扩宽，使用固定表格布局及容器宽度；历史和日志按百分比分配列宽，长文本省略并提供完整内容提示。
- `ProductLog.tsx` 与 `Statistic.tsx` 在挂载时读取已有选中记录，切换记录时清空旧数据，忽略已失效或卸载后的请求响应；失败时不显示上一条记录的数据。不修改 C# 接口。

- 产品历史和产品日志表格字号统一为 12px，行高 16px，单元格内边距收紧；区域标题为 14px。导出按钮允许换行，路径单独一行省略显示。统计表仍保持原有 12px 字号。
